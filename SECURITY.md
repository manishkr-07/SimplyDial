## Reporting a Vulnerability

The SimplyDial team takes security and user privacy seriously. All call recordings, contact directories, and phone logs are processed 100% on-device with zero remote telemetry.

If you believe you have discovered a security vulnerability or privacy leak in SimplyDial, please report it privately:

- ✉️ **Security Contact**: [manis781701@zohomail.in](mailto:manis781701@zohomail.in)
- 🌐 **Developer Portal**: [manish.dev](https://manishkr-dev.vercel.app/)

Please provide:
- A description of the issue.
- Steps to reproduce or proof-of-concept.
- Any potential impact on user data or device security.

We will review your submission promptly, keep you informed of our progress, and publish a fix in an upcoming release. Please **do not** open public issues for sensitive security vulnerabilities until a patch is available.
